# 登记用生成件

本目录由脚本生成，供打印或上传登记窗口。**权威正文仍是上级目录的 Markdown。**

| 文件 | 用途 |
| :--- | :--- |
| `00`–`05` `.docx` | 申请说明、需求、设计、手册、鉴别说明、评估建议 |
| `源程序鉴别材料-前30页.docx` | 自研源程序前 1 500 行 |
| `源程序鉴别材料-后30页.docx` | 自研源程序后 1 500 行 |
| `source-*.txt` | 同上内容的纯文本，便于核对行数 |

重新生成：

```bash
python3 docs/export_source_identification.py
# 再按 docs/04 用 pandoc 转 Word（或重新运行工程内转换命令）
```
