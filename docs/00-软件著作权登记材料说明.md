## 2 软件简介（申请表「软件功能和技术特点」）

溯知是面向研究与知识策展场景的学术长文生成系统。用户输入研究主题后，系统自动生成多专家视角，经网络检索与可选本地语料混合召回，将证据沉淀为事实池与事实图谱，再编排大纲、并行起草章节，并经学术评审与反思修正后输出带引用的长文。用户可在 Web 控制台实时观察探索轨迹，或通过命令行批处理；成果可导出 IEEE/ACM 风格 Typst 论文、Marp 幻灯片与自包含离线研报。任务状态以 SQLite 持久化，支持中断后续跑。

技术特点：纯异步轻量内核（httpx + asyncio + Pydantic v2，运行时不依赖 PyTorch/DSPy）；动态递归探索树按信息增益下钻；RRF 融合本地 BM25 与 Web 检索；SSE 流式进度；四层优先级配置中心；产品视觉遵循鹿溪联合创新实验室 CI。
