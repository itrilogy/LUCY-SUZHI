## 1 结论摘要

溯知 V1.0 已经具备可演示、可中断恢复的深度研究闭环：五阶段管线、SearXNG 混合检索、事实池与图谱、Web SSE 控制台、多格式导出和配置中心。作为实验室「工坊·一法」的知识策展工作站，**主路径功能完整度达到可内网试用**，但距离「可对公网或非可信网络交付」还有安全与产品化缺口。

历史 `素材/` 中大量 P0（连接池、事实去重、评审截断等）已在当前代码中落地，不宜再当作未修缺陷。本评估只记录 **当前仍成立** 的问题。

## 2 架构快照

| 层次 | 现状 | 评价 |
| :--- | :--- | :--- |
| 上游 Stanford STORM | `storm_wiki` / `collaborative_storm` 仍在树内 | 许可需披露；易与自研主路径混淆 |
| 自研异步内核 | 16 个模块，Pydantic 契约 + SQLite 检查点 | 主交付物，结构清楚 |
| HTTP | FastAPI 16 个路由，SSE 队列 | 够用；无鉴权 |
| 控制台 | 原生 HTML/CSS/JS，已套鹿溪 VI | 无构建步骤，利于内网；CDN 依赖 marked/mermaid |
| CLI | runner + wizard + diagnostics | 与 ConfigHub 存在双配置痕迹 |
| 测试 | `tests/` 多套 | 主路径有回归；UI 无浏览器级测试 |

数据流：主题 → 视角 →（探索树 \| 标准问答）→ FactPool → Outline → 图谱+并行写作 → 评审/反思 → 导出/知识库。

## 3 功能完整性

| 能力 | 状态 | 说明 |
| :--- | :--- | :--- |
| 多视角发现 | 可用 | 解析失败有中文/英文回退角色 |
| 深度探索树 | 可用 | 依赖检索质量；增益阈值偏经验 |
| 标准策展 | 可用 | `deep_research=false` |
| 混合检索 RRF | 可用 | 需本机目录真实存在 |
| 事实去重 | 可用 | 规范化哈希，非语义去重 |
| 事实图谱 / 分歧 | 可用 | 质量随模型波动 |
| 图表 | 部分 | Mermaid 语法仍可能被模型写坏 |
| 评审反思 | 可用 | 章节级修补，避免整篇截断 |
| Web 流式 | 可用 | 有重连；进度为阶段映射非真实 ETA |
| 任务恢复 | 可用 | SQLite 为单一事实源之一 |

## 4 仍成立的问题（按优先级）

### P0 — 交付前应处理

| ID | 问题 | 证据与影响 | 建议 |
| :--- | :--- | :--- | :--- |
| P0-1 | 服务默认 `0.0.0.0:8000` 且 **无鉴权** | `server/app.py` `run_server`；任意内网主机可发起耗 Token 的研究、读任务、改配置 | 默认绑定 `127.0.0.1`；需要局域网时显式开关；至少加共享令牌 |
| P0-2 | CORS `allow_origins=["*"]` 且 `allow_credentials=True` | 与浏览器 CORS 规范冲突，且放大跨站调用面 | 改为明确白名单，凭据模式不要配 `*` |
| P0-3 | 仓库含 `path/to/venv/` 万级第三方文件 | 污染发行物与软著源程序范围；`find_packages()` 会扫进去 | 已写入 `.gitignore`，仍须从版本库移除 |
| P0-4 | README 徽章曾写 Apache 2.0，根许可证为 MIT（Stanford） | 权利声明不一致 | **本轮已改** README + `COPYRIGHT.md` / `NOTICE.md` |
| P0-5 | 「脱敏」配置仍把明文 `api_key` 返回浏览器 | `config_hub.py` `get_masked_config` 只加了 `api_key_masked`，未 `pop("api_key")`；`GET /api/v1/config/providers` 原样下发 | 只保留 `has_key` + masked；保存时空密钥表示保持原值 |
| P0-6 | `local_docs_dir` 可指向任意本机目录 | `HybridRetriever` 递归读 `.txt/.md/.json/.log`，可把 `/etc`、家目录编进事实池 | 限制在工程根下白名单；拒绝绝对路径穿越 |
| P0-7 | `task_id` 用于删除/下载未校验 | `resume_task_id=../../` 可使 `rmtree` / `FileResponse` 跳出 `results_async`（filename 有白名单，task_id 没有） | 限制为 `^storm_[a-f0-9]{8}$`，`resolve().relative_to(results_async)` |
| P0-8 | `/api/v1/config/probe` SSRF | 对用户 URL 直接 `httpx.get` | 禁止私网 / 云 metadata |
| P0-9 | 正文与引用 XSS | `marked.parse` 后 `innerHTML`；mermaid `securityLevel: "loose"`；引用卡未 `escapeHtml` | DOMPurify 或转义；mermaid `strict`；引用字段转义 |

### P1 — 显著影响体验或成本

| ID | 问题 | 建议 |

| P1-5 | 进度条为阶段常量，不是真实剩余时间 | 文案改为「阶段进度」，或按历史任务做粗 ETA |

| P1-10 | `fetch_deep_markdown`、知识库冷启动、Encoder/Reranker、Typst PDF **未接入主链路** | **已落地**：检索前列 Jina/直连提纯；本地库先验注入；`SUZHI_RERANK_API_BASE` 可选重排；导出尝试编译 PDF |

## 6 建议演进（不阻塞 V1.0 登记）

1. **安全基线**：本机绑定 + 可选 Token + CORS 白名单。  
2. **配置统一**：删除重复的 `cli/config_manager` 主路径。  
3. **信源治理**：垃圾站规则可在配置中心查看数量与最近拦截。  
4. **对照与审计**：把思考轨迹与事实池做成可下载的研究档案，服务课题验收。  
5. **与 AXON 衔接**：若服务专卖知识工程，将 FactEntry 映射为 AKU 字段（来源、效力、业务域），而不是另起一套 RAG。
