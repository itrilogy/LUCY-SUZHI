## 阅读顺序

1. 对外登记、权属：先读 **00**。  
2. 评审/验收：按 **01 → 02 → 03**。  
3. 提交鉴别材料：按 **04** 抽取源程序。  
4. 日常使用：只读 **03**。  
5. 后续迭代：读 **05**。
