## 1 软件是什么

溯知是跑在你自己电脑或内网里的深度研究与长文生成工作台。输入一个课题，它会从多个专家视角去检索、核对、写大纲、起草章节，并把带引用的文章显示出来，还可以导出论文、幻灯片和离线研报。

标语：**溯流求源，知汇成章。**  
出品：鹿溪联合创新实验室。  
引擎代号：STORM。

生成内容依赖你配置的大模型与搜索服务，**不能替代**人工审稿。涉及机密的课题请只在内网使用，不要把密钥和语料放到公网。

## 2 运行环境

- 操作系统：macOS 或 Linux（Windows 可用，但未作为主交付环境）。  
- Python 3.10 或更高。  
- 现代浏览器（Chrome / Edge / Safari / Firefox）。  
- 网络：能访问你选用的 LLM API；检索需 SearXNG 或同等端点。  
- 可选：安装 [Typst](https://typst.app/) 以便把论文源编译为 PDF。  
- 无需 GPU。

## 3 安装

在工程根目录：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m server.app
```

不要用未激活虚拟环境的系统 `python3` 直接跑服务，否则会报 `No module named 'fastapi'`。

不要把第三方虚拟环境目录提交进仓库。

## 4 配置模型与检索

至少准备：

1. 一个 OpenAI 兼容的对话接口（如 DeepSeek、SiliconFlow、Ollama）。  
2. 一个 SearXNG 搜索接口。

### 4.1 环境变量（适合临时试用）

```bash
export DEEPSEEK_API_KEY="sk-your-key"
export DEEPSEEK_API_BASE="https://api.deepseek.com"
export SEARXNG_API_URL="https://your-searxng.example/search"
```

### 4.2 用户配置文件（适合长期使用）

编辑 `~/.storm/config.toml`，指定活跃厂商、模型名、Base URL 与检索地址。也可启动 Web 后在 **配置中心** 填写并保存。

密钥只存在本机。配置查询接口会脱敏，但本机磁盘上的 TOML 仍是明文，请保护好家目录权限。

## 5 启动 Web 控制台（推荐）

```bash
source .venv/bin/activate
python -m server.app
```

浏览器打开：`http://127.0.0.1:8000`

若服务监听在 `0.0.0.0`，局域网内其他机器也可访问。**不要**在未设反向代理与访问控制的情况下映射到公网。

### 5.1 第一次进入

顶栏左侧是溯知方标与标语。右侧依次为：

| 按钮 | 作用 |
| :--- | :--- |
| 任务列表 | 查看历史与进行中的研究 |
| 知识库 | 本机已沉淀课题（只读，供后续冷启动） |
| 新建研究 | 清空当前视图，准备新主题 |
| 配置中心 | 切换模型/检索并探测连通 |
| 关于 | 产品说明、出品方、上游许可说明 |
| 就绪指示 | 空闲为绿，运行中为闪烁 |

页脚为鹿溪联合创新实验室主标与出品声明。

### 5.2 发起一次研究

1. 在左侧「研究课题 / 论文主题」填写题目（中英文均可）。  
2. 需要深挖时保持「深度研究模式」开启，选择探索深度 1–3 与专家视角数。  
3. 若有本机资料，填写语料目录路径（Markdown/文本等）。  
4. 点击 **启动深度研究**。  
5. 观察演进轴与思考轨迹：视角发现 → 知识策展 → 大纲 → 正文 → 评审润色。  
6. 右侧逐步出现正文；引用角标可跳到参考文献。

任务进行中可点 **中断任务**。稍后在任务列表中选中该任务即可从断点继续（需再次启动并指定恢复，或从列表恢复入口进入）。

### 5.3 查看与导出

| 页签 / 按钮 | 作用 |
| :--- | :--- |
| 正文渲染 | Markdown 与图表 |
| 参考文献 | 信源卡片，点击正文角标会高亮对应条目 |
| Markdown 源码 | 原始文本 |
| Typst 论文 | 本机已安装 Typst CLI 则下载 PDF，否则下载 `.typ` |
| Marp 幻灯片 | 生成演讲稿 Markdown |
| 离线研报 | 自包含 HTML（溯知页眉，无外网脚本），可拷走打开 |
| 复制 Markdown | 写入剪贴板 |

成果同时写在 `results_async/<任务编号>/`。

### 5.4 配置中心

1. 选择活跃 LLM 厂商，填写 Base URL。  
2. 密钥框留空表示不改动已保存密钥；输入新值将覆盖。  
3. 点 **探测并拉取模型** 测延迟并列出可用模型。  
4. 同样探测 SearXNG。  
5. **保存并应用配置** 立即生效，不必重启。

### 5.5 任务列表

显示主题、阶段、是否在跑。可刷新、进入、停止、删除。顶部两个下拉框可选两场任务做 **复跑对比**（unified diff）。删除会去掉检查点，磁盘成果需手工清理的，请同时检查 `results_async/`。

## 6 命令行用法

适合批处理或不打开浏览器时：

```bash
python3 -m cli.async_runner --topic "Vibe Coding as a Paradigm for AI-Assisted Software Development"

python3 -m cli.async_runner \
  --topic "本地大模型在专卖内网的部署约束" \
  --deep-research \
  --max-depth 2 \
  --perspectives 4 \
  --local-docs-dir ./raw_sources

python3 -m cli.async_runner --resume storm_ab12cd34
```

交互向导与诊断：

```bash
python3 -m cli.interactive_wizard
python3 -m cli.diagnostics
```

输出目录默认 `./results_async`。

## 7 阅读生成结果时要注意

1. **先看引用**：没有出处的关键数字应人工复核。  
2. **看冲突表**：事实图谱若标出分歧，正文可能同时保留对照，需要你裁决。  
3. **中英文主题**：题目用中文，正文倾向中文；纯英文题目倾向英文。  
4. **深度越大越慢、越费 Token**：日常用 2 层即可。  
5. **本地语料**：路径必须是运行服务的机器上的真实目录，浏览器不能上传整个文件夹。

## 8 常见问题

| 现象 | 可能原因 | 处理 |
| :--- | :--- | :--- |
| 启动失败「请输入研究课题」 | 主题为空 | 至少 2 个字符 |
| 429 并发上限 | 已有 3 个任务在跑 | 等待或停止旧任务 |
| 检索一直失败 | SearXNG 地址/网络/引擎名不正确 | 配置中心探测；检查 URL 是否含 `/search` |
| 模型 401 | 密钥错误或未保存 | 重新填写密钥并保存 |
| SSE 断开 | 网络闪断 | 控制台会自动重连最多 5 次；刷新页面可从上次任务恢复 |
| 导出 PDF 失败 | 未安装 Typst | 先使用 `.typ` 源，或安装 Typst 后再导出 |
| 页面没有图标/样式 | 静态路径未托管 | 确认从 `python3 -m server.app` 启动，不要直接打开 HTML 文件 |
| 结果像「网文拼贴」 | 检索命中低质站 | 同步垃圾站规则，或改用学术引擎轨 |
