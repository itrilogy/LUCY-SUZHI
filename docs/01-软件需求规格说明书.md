## 1 引言

### 1.1 目的

规定「溯知」V1.0 的范围、功能需求、非功能需求、接口与约束，作为设计、实现、测试与软著说明书的需求基线。

### 1.2 范围

软件根据用户给定的研究主题，自动完成多视角知识策展、带引用的学术长文生成与多格式出版。提供 Web 控制台与命令行两种使用方式。不包含公有云账号体系、付费结算、对第三方大模型本身的训练，也不将 Stanford STORM 上游同步管线作为本版本交付范围。

### 1.3 定义

| 术语 | 定义 |
| :--- | :--- |
| 溯知 | 本软件产品名；英文 SuZhi；引擎代号 STORM |
| 视角 / Persona | 针对主题生成的专家角色，用于多角度提问与检索 |
| 事实池 FactPool | 经去重的原子事实集合，带信源 URL 与置信度 |
| 探索树 | 按信息增益递归下钻的动态研究树 |
| 事实图谱 | 实体-关系三元组及跨信源分歧记录 |
| 任务 | 一次主题研究的全生命周期，以 `task_id` 标识 |
| 断点续跑 | 从 SQLite 检查点恢复未完成阶段 |
| ConfigHub | 四层优先级配置中心（CLI > 环境变量 > TOML > 预置） |
| SSE | Server-Sent Events，服务端向控制台推送阶段事件 |

## 2 总体描述

### 2.1 产品前景

将「提出主题 → 人工检索资料 → 手工写长文」收敛为可恢复的自动化管线，并以「溯流求源、知汇成章」强调引用可追溯与出版可用。

### 2.2 用户

内网研究人员、课题组成员与信息化运维人员。V1.0 不设多租户与角色分级；配置与密钥由部署方自行保管。

### 2.3 运行环境

见 `00` 第 1 节。Web 默认端口 8000。需可达的 OpenAI 兼容 LLM 端点，以及 SearXNG 或同等检索端点。

### 2.4 约束

1. 运行时不捆绑 GPU 与 PyTorch。  
2. 生成文本的事实性依赖于检索质量与模型能力，软件提供引用与冲突表，不构成法律/学术担保。  
3. API 密钥不得出现在前端日志与 Provider 查询接口的明文回传中（应脱敏）。  
4. Stanford STORM 上游目录不作为本版本功能入口。  
5. 产品界面中文名为「溯知」，出品方为鹿溪联合创新实验室。

### 2.5 假设

用户可提供合法的模型与检索凭据；本机或内网磁盘可写 `results_async/` 与配置目录；浏览器支持 EventSource。

## 3 功能需求

需求编号规则：`FR-模块-序号`。优先级：M 必须 / S 应当 / C 可以。

### 3.1 品牌与关于（FR-BR）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-BR-01 | 页面标题、顶栏字锁为「溯知 · SuZhi」，标语「溯流求源，知汇成章」 | M |
| FR-BR-02 | 使用溯知方标与 favicon；页脚与关于页展示实验室主标及出品方 | M |
| FR-BR-03 | 关于页说明引擎代号 STORM，并披露上游 Stanford STORM（MIT）非本软件客体 | M |

### 3.2 研究管线（FR-PL）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-PL-01 | 输入主题后执行五阶段：视角发现 → 知识策展 → 大纲编排 → 正文起草 → 评审润色 | M |
| FR-PL-02 | 视角数量可配置（2–6），中英文主题自动选择回复语言 | M |
| FR-PL-03 | 深度研究模式启用动态递归探索树，最大深度 1–3（实现允许至 4） | M |
| FR-PL-04 | 非深度模式走标准多轮问答策展 | S |
| FR-PL-05 | 事实入池须去重，记录信源 URL、标题、视角与质量分 | M |
| FR-PL-06 | 抽取事实图谱并生成跨信源分歧对照，可供写入正文 | M |
| FR-PL-07 | 章节可并行起草；正文须带引用标记 | M |
| FR-PL-08 | 学术多维评审；未通过则触发反思修补 | S |
| FR-PL-09 | 可选生成 Mermaid/SVG 机制图 | S |
| FR-PL-10 | 完成后落盘 article、outline、citations、事实池及导出物 | M |

## 5 外部接口

### 5.1 用户界面

`frontend/web/index.html` 单页控制台，由 FastAPI 在 `/` 托管。

### 5.2 软件接口（REST / SSE）

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/` | 控制台 |
| POST | `/api/v1/research/start` | 启动或恢复任务 |
| GET | `/api/v1/research/stream/{task_id}` | SSE 事件 |
| POST | `/api/v1/research/stop/{task_id}` | 停止 |
| GET | `/api/v1/tasks` | 任务列表 |
| DELETE | `/api/v1/tasks/{task_id}` | 删除 |
| GET | `/api/v1/research/article/{task_id}` | 取文 |
| POST | `/api/v1/export/typst/{task_id}` | Typst |
| POST | `/api/v1/export/slides/{task_id}` | Marp |
| POST | `/api/v1/export/html/{task_id}` | HTML |
| GET | `/api/v1/download/{task_id}/{filename}` | 下载 |
| GET/POST | `/api/v1/config/*` | 配置、探测、垃圾站规则 |

### 5.3 外部系统

- OpenAI 兼容 Chat Completions  
- SearXNG `/search`  
- 可选 Jina Reader 全文提纯  
- 可选 Typst 可执行文件
